# Kitapçık Oluşturucu

AÖL Deneme Sistemi için öğrenci kitapçığı ve giriş belgesi oluşturan Windows programı.

**İndir:** [KitapcikOlusturucu.exe](https://github.com/ibrahimgkta-cell/kitapcik-olusturucu/releases/latest/download/KitapcikOlusturucu.exe)

Kurulum gerektirmez; indirip çalıştırın. Windows "bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır**.

Bu depo yalnızca indirme içindir. Programın kaynağı AÖL Deneme Sistemi deposundadır.
